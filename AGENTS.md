# Preferencias de trabajo del proyecto

- Usar la skill `graphify` para explorar el código, la arquitectura y las relaciones del proyecto de aquí en adelante, por pedido del usuario.
- Consultar primero `graphify-out/graph.json` cuando exista y usar las consultas, rutas y explicaciones de Graphify para orientar la exploración. Verificar en los archivos fuente los detalles que se vayan a modificar.
- Mantener el grafo actualizado cuando cambien los archivos incluidos en su alcance y regenerar `graphify-out/graph.html` para conservar el mapa interactivo.
- Si todavía no existe un grafo, crearlo siguiendo la skill de Graphify. Respetar el alcance acordado con el usuario y documentar los archivos o formatos omitidos.
